# Spec trial

A trial of the kit's game spec proposal (`docs/game-spec-proposal.md` in the kit):
write down what the game does, from its code, and see how much of it was never decided on purpose.

- [game-spec.md](game-spec.md): the spec of version 1.4.0, in the game's terms, with the numbers.
- [decisions.md](decisions.md): what the code does that nobody chose, and where it differs from
  the design guide. These need your ruling.
- [notes/](notes/): the readers' raw notes with line numbers. Not checked by running the game.

Scope of this trial: spec only. No code was changed and nothing was rebuilt from the spec.
